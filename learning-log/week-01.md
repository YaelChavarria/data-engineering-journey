# Bitácora: Semana 1

## Objetivo

Preparar un entorno de trabajo reproducible y entender las herramientas base para continuar con el plan de Data Engineering.

## Completado

- Git y Python disponibles.
- Docker y VS Code preparados.
- Entorno virtual de Python creado.
- Dependencias iniciales instaladas y verificadas.
- Limitación identificada: el equipo no dispone de GPU NVIDIA.
- Limitación identificada: algunas compilaciones nativas en Windows pueden requerir WSL2 o Microsoft Build Tools.

## Aprendizajes

- Un entorno reproducible evita que los problemas de instalación oculten los problemas reales del código.
- Las herramientas de gestión de entornos deben documentarse junto con sus versiones y comandos.
- Para cargas pesadas de AI o datos, conviene decidir por adelantado qué se ejecutará localmente y qué se ejecutará en cloud.
