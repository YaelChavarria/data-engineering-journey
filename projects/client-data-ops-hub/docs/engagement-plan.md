# Engagement Plan

## Phase 1: Discovery

**Goal:** agree on decisions, sources and responsibilities before building.

- Interview business owners and current report users.
- Inventory source systems, owners, frequency and access method.
- Capture current pain points and manual workarounds.
- Define the first scorecard and acceptance criteria.
- Identify sensitive fields and retention constraints.

**Exit criteria:** signed metric definitions, source inventory, scope and delivery cadence.

## Phase 2: Foundation

**Goal:** turn the agreement into a repeatable data contract.

- Create source schemas and field-level expectations.
- Build intake checks and quarantine rules.
- Create typed Bronze and Silver layers.
- Add key, relationship, domain and freshness checks.
- Record decisions and unresolved risks.

**Exit criteria:** a clean sample export passes the quality gate and can be replayed.

## Phase 3: Delivery

**Goal:** produce outputs a client team can use without analyst intervention.

- Build the scorecard and operational tables.
- Reconcile totals against client-approved definitions.
- Add a dashboard or BI handoff.
- Publish the quality report and delivery manifest.
- Run a review with Finance, Operations or Customer Success.

**Exit criteria:** client signs off on the deliverables and known limitations.

## Phase 4: Operate and improve

**Goal:** make recurring data work dependable.

- Monitor delivery status, freshness and failed checks.
- Triage incidents according to the runbook.
- Review metric changes through the data contract process.
- Keep an improvement backlog and revisit scope monthly.

## Example responsibilities

| Responsibility | Data partner | Client |
|---|---|---|
| Define business decisions | Lead | Approve |
| Provide source exports | Support | Own |
| Operate pipeline | Own | Review |
| Validate metric meaning | Facilitate | Approve |
| Respond to source changes | Triage | Notify |
| Accept delivery | Prepare evidence | Sign off |
